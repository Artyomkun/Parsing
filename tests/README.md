# Тесты проекта (смоук + e2e)

Папка содержит e2e-сьюты, доказывающие, что конвертации (аудио/видео/PDF) работают
на happy-path и на краевых случаях — как на синтетике, так и на реальных файлах из интернета.

## Состав

| Файл | Что проверяет | Интернет |
|---|---|---|
| `synthetic.test.ts` | Синтетические фикстуры (ffmpeg `lavfi`, минимальный PDF): все 5 контейнеров аудио с проверкой магических байтов и ffprobe, опции кодирования (bitrate/sampleRate/channels), `data:` URL, голый base64, извлечение звука из видео, **краевые случаи**: пустой ввод, мусор вместо файла, видео без аудиодорожки, битый JSON-payload, неизвестный тип, транскрипция без ключа / с mock-Whisper / с ошибками API (500, пустой ответ, без сегментов), битый и пустой PDF | нет |
| `real-world.test.ts` | Реальные публичные файлы (MDN, Wikimedia, GitHub raw, W3Schools, pdfobject): MP3/WAV/OGG/M4A → все форматы, видео Big Buck Bunny → MP3, PDF → текст/JSON. Кэш в `.cache/`, недоступность сети -> SKIP, а не FAIL | да |
| `http-e2e.test.ts` | E2E через реальный express: `GET /convert/types`, `POST /convert` (single + цепочка mp3→ogg→flac), коды ошибок 400/500. Порт выбирается свободный, чтобы не конфликтовать с dev-сервером | нет |
| `helpers.ts` | Мини-раннер `Suite`, ffmpeg/ffprobe-обёртки, генераторы фикстур, mock Whisper-API, скачивание с кэшем | — |
| `run-all.ts` | Запуск всех сьютов + генерация `REPORT.md` | частично |
| `REPORT.md` | Автогенерируемый отчёт последнего прогона (статусы, тайминги, платформа) | — |

## Запуск

```bash
pnpm test:smoke            # всё + перезапись tests/REPORT.md
pnpm test:smoke:synthetic  # только синтетика (офлайн)
pnpm test:smoke:real       # только реальные данные (нужен интернет)
pnpm test:smoke:http       # только e2e через express
```

Каждый файл запускается и standalone (`tsx tests/synthetic.test.ts`).

## Замечания

- **Транскрипция** (`audio2srt/vtt`) тестируется против локального mock Whisper-совместимого
  API поверх HTTPS: mock слушает только `127.0.0.1`, а самоподписанный сертификат
  генерируется при первом запуске теста (`selfsigned`), поэтому в репозитории нет
  приватного ключа. `withMockEnv` добавляет сертификат мока в список доверенных CA
  (`tls.setDefaultCACertificates`) и восстанавливает его после тестов; глобальная
  проверка TLS не отключается. Проверяются multipart (model/language/Authorization),
  таймкоды SRT/VTT, fallback «один cue на всю длительность», обработка 500 и пустого
  ответа. Для прогона против реального API задайте `WHISPER_API_KEY` (или
  `OPENAI_API_KEY`) в окружении — код подхватит их автоматически.
- Реальные файлы кэшируются в `tests/.cache/` (в `.gitignore`) — повторные прогоны идут офлайн.
- Отчёт `REPORT.md` перезаписывается при каждом `pnpm test:smoke`.
